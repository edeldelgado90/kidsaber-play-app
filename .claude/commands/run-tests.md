# Run Tests

Runs the full Jest test suite with coverage.

```bash
cd /Users/edelgado/Projects/kidsaber-play-app && npm run test -- --coverage --verbose
```

After running, report:

- Number of test suites and tests that passed / failed
- Overall coverage percentages (statements, branches, functions, lines)
- Any failing tests with their error messages

If tests fail, identify the root cause and suggest a fix.
